RetailHub WebSocket API

← REST API (Swagger)
Протокол: STOMP 1.2 over WebSocket + SockJS fallback
Endpoint: ws://<host>/ws (через Gateway)

Каналы подписки

SUBSCRIBE /topic/store/{storeId}/requests
STOMP

Обновления заявок магазина. Подписчик: менеджер.
Получает уведомления при создании, ожидании, эскалации, назначении, завершении и переназначении заявок магазина.

ПараметрТипОписание
storeIdUUIDID магазина (из JWT claims)
SUBSCRIBE /topic/department/{departmentId}/requests
STOMP

Обновления заявок конкретного отдела. Подписчик: консультант.
Получает уведомления о новых заявках, ожидании (WAITING) и переназначении.

ПараметрТипОписание
departmentIdUUIDID отдела
SUBSCRIBE /queue/request/{clientSessionToken}
STOMP

Статус конкретной заявки. Подписчик: клиент (после сканирования QR).
Получает обновления жизненного цикла заявки (создание, ожидание, эскалация, назначение, завершение, отмена, переназначение). Заменяет polling GET /requests/{id}?session=.

ПараметрТипОписание
clientSessionTokenUUIDКлиентская сессионная метка заявки (из ответа POST /requests)

Типы событий

СобытиеКаналыОписание
REQUEST_CREATED store, department, client Клиент создал заявку через QR
REQUEST_WAITING store, department, client Заявка ждёт > 3 мин, повторное уведомление консультантам
REQUEST_ESCALATED store SLA нарушен (> 5 мин), уведомление менеджеру
REQUEST_ASSIGNED store, client Консультант взял заявку
REQUEST_COMPLETED client Обслуживание завершено
REQUEST_CANCELED store, client Клиент отменил заявку
REQUEST_REASSIGNED store, department Клиент запросил смену консультанта
REQUEST_REMINDED — Клиент напомнил (только FCM push, не WebSocket)

{
  "eventType": "REQUEST_ASSIGNED",
  "requestId": "a1b2c3d4-...",

  "departmentId": "2222-...",

  "status": "ASSIGNED",
  "assignedUserId": "4444-...",
  "assignedUserName": "Test Consultant",

  "timestamp": 1712116800000
}

Пример подключения (JavaScript)

const socket = new SockJS(window.location.origin + '/ws');
const stompClient = Stomp.over(socket);

stompClient.connect({}, () => {
    // Менеджер: все заявки магазина
    stompClient.subscribe('/topic/store/1111-.../requests', (msg) => {
        const update = JSON.parse(msg.body);
        console.log('Store update:', update.eventType, update.status);
    });

    // Консультант: заявки своего отдела
    stompClient.subscribe('/topic/department/2222-.../requests', (msg) => {
        const update = JSON.parse(msg.body);
        console.log('Dept update:', update.eventType, update.status);
    });

                    // Клиент: статус своей заявки (по clientSessionToken)
                    stompClient.subscribe('/queue/request/5555-...', (msg) => {
        const update = JSON.parse(msg.body);
        console.log('My request:', update.status);
    });
});
